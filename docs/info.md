# II20Task - Kotlin Multiplatform Project

## Обзор проекта

**II20Task** - это современный Kotlin Multiplatform проект, разработанный с использованием передовых технологий JetBrains. Проект состоит из десктопного приложения на базе Compose Multiplatform и серверной части на Ktor, что позволяет создать комплексное решение с общей кодовой базой.

## Архитектура проекта

Проект организован по модульному принципу с тремя основными компонентами:

### 1. Модуль `composeApp`
- **Назначение**: Десктопное приложение для JVM платформы
- **Технологии**:
  - Compose Multiplatform 1.9.1
  - Kotlin 2.2.20
  - Compose Compiler и Hot Reload для ускорения разработки
- **Структура**:
  - `src/jvmMain/kotlin/org/ufku/ii20task/` - основная логика приложения
  - `src/jvmMain/composeResources/` - ресурсы UI
  - `src/jvmMain/kotlin/org/ufku/ii20task/mcp/` - MCP (Model Context Protocol) компоненты

### 2. Модуль `server`
- **Назначение**: Серверное приложение на Ktor
- **Технологии**:
  - Ktor 3.3.1 с Netty сервером
  - Порт по умолчанию: 8080
  - Поддержка CORS, логирования и сериализации JSON
- **Функциональность**:
  - REST API эндпоинты
  - Веб-сервер для обработки HTTP запросов

### 3. Модуль `shared`
- **Назначение**: Общий код для всех платформ
- **Компоненты**:
  - `Greeting.kt` - класс приветствия с платформо-зависимой логикой
  - `Constants.kt` - общие константы (SERVER_PORT = 8080)
  - `Platform.kt` - абстракции платформо-зависимых функций

## Ключевые зависимости

### Основные фреймворки:
- **Kotlin Multiplatform**: 2.2.20 - основа для кросс-платформенной разработки
- **Compose Multiplatform**: 1.9.1 - декларативный UI фреймворк
- **Ktor**: 3.3.1 - асинхронный HTTP клиент и сервер

### MCP интеграция:
- **mcp-kotlin**: 0.7.7 - SDK для Model Context Protocol
- Поддержка как клиентских, так и серверных MCP реализаций

### Дополнительные библиотеки:
- **Kotlinx Coroutines**: 1.10.2 - асинхронное программирование
- **Logback**: 1.5.20 - логирование
- **dotenv-kotlin**: 6.5.1 - управление переменными окружения
- **zai-sdk**: 0.1.0 - AI интеграция

## Функциональность

### Текущие возможности:
1. **Десктопное приложение** с современным UI на Compose
2. **Веб-сервер** с базовым REST API
3. **MCP протокол** для интеграции с AI моделями
4. **Кросс-платформенный** общий код
5. **Hot Reload** для ускорения разработки UI

### Серверные эндпоинты:
- `GET /` - возвращает приветствие с информацией о платформе

## Сборка и запуск

### Десктопное приложение:
```bash
# Windows
.\gradlew.bat :composeApp:run

# macOS/Linux
./gradlew :composeApp:run
```

### Сервер:
```bash
# Windows
.\gradlew.bat :server:run

# macOS/Linux
./gradlew :server:run
```
